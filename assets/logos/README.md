# Logos de loterías

Este proyecto no incluye logos oficiales porque no fueron suministrados con licencia o autorización verificable. `LotteryLogo` muestra un identificador genérico de respaldo y nunca imita una marca registrada.

Para integrar un logo oficial: agregar el activo autorizado en esta carpeta, registrar su origen/licencia y asociarlo al `id` de la lotería en `src/components/LotteryLogo.js`. Alcance: Lotería Nacional, Leidsa, Real, Loteka, La Primera, La Suerte Dominicana, Lotedom, Anguilla Lottery, Nueva York y Florida.
