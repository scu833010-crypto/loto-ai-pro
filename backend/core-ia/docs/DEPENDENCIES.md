# Dependencias

- Runtime: Node.js 20 o superior.
- Produccion: ninguna dependencia externa.
- Pruebas: `node:test` y `node:assert`, incluidos en Node.js.

El paquete evita acoplarse a ORM, HTTP framework, Expo o bibliotecas de machine learning. El backend anfitrion elige PostgreSQL y su adaptador de repositorio.
