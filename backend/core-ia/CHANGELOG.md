# Changelog

## 0.2.0 — 2026-07-17

- Se agregan tendencias, correlacion descriptiva y simulacion de ventanas historicas.
- Se agrega memoria append-only inyectable, aprendizaje basado en evidencia y propuesta de configuracion con aprobacion externa.
- Se amplian contratos de API, documentacion, diagrama de dependencias y pruebas de integracion.

## 0.1.0 — 2026-07-17

- Paquete desacoplado de analisis historico para LOTO IA RD.
- Validacion estricta de resultados con fuente real identificable.
- Estadisticas, frecuencia relativa, retrasos, distribuciones, patrones, ranking y explicaciones.
- Evaluacion retrospectiva contra una linea base aleatoria.
- API interna sin dependencia de framework web.
- Pruebas unitarias y documentacion de arquitectura e integracion.
- No incluye prediccion, confianza de ganar, combinaciones sugeridas ni datos mock.
